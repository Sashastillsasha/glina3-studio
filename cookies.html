Cookies & Local Storage

Configuration check needed: This description reflects the code currently reviewed in the GLINA³ website repository. Re-check it whenever analytics, embeds, fonts, or other scripts change.

Game score

The mini-game stores your best score for the current day in your browser’s local storage under a GLINA³-specific key. It is used only to show your personal daily best on this device. It is not sent to GLINA³ and expires only if you or your browser clear site data. The game does not require this storage to display the rest of the website.

Website analytics

The site loads Cloudflare Web Analytics using a JavaScript beacon. Cloudflare describes this product as not using cookies or browser local storage for its usage metrics. The analytics provider may process technical request data to provide the service; see Cloudflare’s privacy notice.

Fonts and other external services

The current page loads fonts from Google Fonts. When a browser requests those font files, Google receives technical connection data such as the IP address. Consider hosting the font files locally if you do not want this third-party request. The site also links to external sites, which apply their own privacy and cookie practices when you visit them.
