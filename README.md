# GLINA³ — Rebuilding

A lightweight temporary landing page for GLINA³.

- self-contained landing page with a playable Tetris-style mini game
- responsive layout
- Google Fonts are loaded externally
- Cloudflare Web Analytics beacon is included
- the game stores a daily best score in browser local storage
- the email field opens a consent email draft to office@glina3.nl; it does not submit to a mailing-list service
- privacy, cookies/local storage, and legal/company information pages are included as owner-review drafts; verify marked company/provider/retention details before relying on them

Public website: https://sashastillsasha.github.io/glina3-studio/
